# Sample: Neighborhood Clinic Appointment Portal

This example illustrates how one project applies reusable catalog questions without
changing the templates. It is intentionally incomplete: unresolved and dormant items
show that an honest graph can represent uncertainty.

Files:

- `project-profile.yaml`: subject boundary and project metadata;
- `question-instances.yaml`: state, ownership, priority, and transition history;
- `answers.yaml`: versioned answers and evidence references.

The example data is fictional and must not be treated as medical, legal, security, or
operational guidance.
