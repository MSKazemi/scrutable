# Support

This project is maintained by one person, unfunded. These channels are what can honestly be
offered — please read before opening an issue.

## Where to go

| You want to… | Go to |
|---|---|
| Understand how to run the framework | [`QUICKSTART.md`](QUICKSTART.md) |
| Point an AI agent at it | [`ai-context.yaml`](ai-context.yaml), then [`AGENTS.md`](AGENTS.md) |
| See a worked run | [`examples/sample-application/`](examples/sample-application/) |
| Ask a question or propose an idea | [GitHub Issues](https://github.com/MSKazemi/mohsen/issues) |
| Report a security concern | **Privately** — see [`SECURITY.md`](SECURITY.md), not an issue |
| Propose a change | [`CONTRIBUTING.md`](CONTRIBUTING.md) |

## What to expect

Best-effort responses. There is no service-level agreement, no paid support tier, and no
guaranteed response time. Issues that include the revision you used, what you tried, and what
you expected get answered fastest.

## What is out of scope

- Consulting on your specific product, architecture, or compliance obligations.
- Interpreting whether a run's gate result is correct for your situation — that judgment belongs
  to your accountable owner.
- Qualified legal, regulatory, safety, or security advice. This framework is explicitly not a
  substitute for it, and no domain pack is published.

## Most useful thing you can contribute

A record of running the framework on a real project. It has never been applied to an external
subject, so its detection and false-blocker behaviour is unmeasured — a single honest field
report is worth more right now than any number of new questions.
